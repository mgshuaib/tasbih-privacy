# نشر صفحة الخصوصية مجانًا — ٥ دقائق، بلا أوامر

> أبل تطلب **رابطًا** لسياسة الخصوصية قبل النشر. هذه الصفحة جاهزة (`index.html`)، وهذا الملف يشرح كيف تنشرها مجانًا في مستودع صغير **منفصل** — كود التطبيق لا يظهر فيه شيء.

## الخطوات

**① أنشئ المستودع على GitHub**
1. افتح github.com وأنت مسجّل الدخول ← زر **+** أعلى اليمين ← **New repository**.
2. الاسم: `tasbih-privacy`
3. **مهم:** اجعله **Public** (عام) — صفحات GitHub المجانية لا تعمل في المستودع الخاص.
   لا تقلق: هذا المستودع سيحتوي **صفحة الخصوصية فقط**، لا كود التطبيق.
4. اضغط **Create repository**.

**② ارفع الصفحة**
1. في المستودع الجديد اضغط **Add file** ← **Upload files**.
2. اسحب ملف `index.html` من مجلد `tasbih-privacy` الذي نزّلته، وأفلته في الصفحة.
3. اضغط **Commit changes**.

**③ شغّل الصفحة**
1. في المستودع: **Settings** (أعلى) ← في القائمة اليسرى **Pages**.
2. تحت *Branch*: اختر `main` ومن القائمة المجاورة `/(root)` ← اضغط **Save**.
3. انتظر دقيقة واحدة، ثم أعِد تحميل الصفحة: سيظهر أعلاها رابطك، شكله هكذا:

```
https://اسمك-في-جيت-هب.github.io/tasbih-privacy/
```

**④ تأكد أنها تفتح**
افتح الرابط في المتصفح — يجب أن تظهر صفحة «سياسة الخصوصية — تطبيق سبحة».

**⑤ أخبرني**
أرسل لي الرابط، وأضعه في مكانه في ملف «مواد المتجر» مباشرة.
